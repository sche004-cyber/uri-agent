### Acceptance criteria (plan §6), each independently re-traced against final source

1. **Mode narrows, never widens.** `CapabilityResolver.resolve()`/`is_allowed()`: `allowed_ids = registry_ids & user_grants & mode_allowed_ids` (pure set intersection — cannot add capabilities grants/registry excluded). `test_diagnostic_mode_narrows_a_broad_grant`: a user with every registered capability granted, in `diagnostic` mode, resolves to `∅` (diagnostic's packaged allowlist), and `draft_institutional_note`/`gmail_create_draft` are confirmed absent from both `resolve()` and `is_allowed()`.
2. **Default `office` mode = pre-M22.8 behavior.** `test_office_default_preserves_registry_and_grants_intersection`: no `mode` set → `DEFAULT_MODE == "office"` → resolved set equals the grants-only intersection, byte-identical to pre-M22.8 `resolve()`.
3. **`diagnostic` excludes every drafting/write/execution capability.** Confirmed via direct inspection of `modes.py`: `diagnostic: []` — the packaged registry (`extract_student_records`, `draft_institutional_note/order`, `generate_document`, `gmail_search/find_draft/create_draft`, `web_search`, `drive_search/upload`, `fetch_url`, `fetch_drive_spreadsheet`, `read_attached_file`) contains no capability that is safely, honestly classifiable as read-only/reporting-only — every one either drafts, sends, uploads, or reaches an external network resource. An empty allowlist is the correct, fail-closed choice given that reality (not a shortcut): it trivially satisfies "excludes every write capability" without fabricating a false distinction the registry doesn't actually support. `test_diagnostic_packaged_allowlist_has_no_drafting_or_execution_capabilities` confirms this directly against the real registry.
4. **BASIC-tier provider view never renders "token"/"context window".** `providers_screen.dart`'s BASIC-tier subtitle branch confirmed to read "Connect a provider and safely save its access key." (no forbidden words); `uri_ui/test/m22_8_basic_provider_tier_test.dart` renders the real widget tree via `MockUriClient` and asserts both strings are absent from every rendered `Text` — passing, after fixing the `RenderFlex` overflow that was blocking it from ever completing a render.
5. **`GET/PUT /modes` self-scoped, impersonation rejected.** Traced `_resolve_principal`: `mode` is derived solely from `account.mode` looked up by the bearer-token-resolved `user_id` — no client-suppliable `user_id` parameter exists on either route. `test_modes_are_self_scoped_and_ignore_impersonation_fields` authenticates as user A, attempts `PUT /modes?user_id=B&{"mode":"diagnostic","user_id":B}`, and confirms only A's own account changed (`server._user_account_store.get_by_user_id(a_id).mode == "diagnostic"`, `b_id` unaffected) — a genuine attempted-impersonation test, not just an absence-of-parameter check.
6. **`test_experience_tier_never_authorizes.py` unmodified and passing.** Confirmed via `git status` (file untouched) and a direct run: 3/3 passing, including the AST scan proving `mode`'s new authorization logic in `capability_resolver.py` doesn't somehow also reference `experience_tier`.
7. **`orchestrator.py` unchanged.** `git diff HEAD -- uri_core/core/orchestrator.py` is empty; `wc -l` = 5460, identical before and after this milestone. No `principal.mode` reference exists anywhere in `orchestrator.py`, `approval_gate.py`, or `dispatcher.py` — confirmed by direct grep across the whole `uri_core/core/` and `uri_core/app/` trees: the only consultation points are `capability_resolver.py` (the single authoritative one) and `server.py`'s own `/modes` handlers (reporting the value, not deciding authorization with it).
8. **Full regression suite.** Python: `pytest -o python_files="test_*.py"` → **1,460 passed, 0 failures** (reproduced from scratch; 1,452 pre-M22.8 baseline + 8 new). Flutter: `flutter analyze` → **0 errors** (8 pre-existing-pattern info lints, unchanged in kind from prior milestones); `flutter test` → **112/112 passed** (111 pre-existing + 1 new), reproduced from scratch after fixing the two real bugs the run itself surfaced.
