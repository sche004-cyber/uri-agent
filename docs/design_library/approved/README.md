# Approved design decisions

This folder holds one record per screen (or major structural decision)
once it has actually been selected — not proposed. Do not place a
candidate here while it is still one of several options under review;
those stay described in the relevant category `README.md` or in a
directions document (e.g. `docs/design_library/UI_DIRECTION_OPTIONS.md`)
until the User picks one.

## Record format

Name each file `<screen-or-decision>_<YYYY-MM-DD>.md` and include:

- What was decided (the concrete structure/layout chosen).
- Which reference(s) it was adapted from, and which category `README.md`
  supplied the supporting URI backend evidence.
- Why it was chosen over the alternatives that were considered.
- Which URI backend capability/data it maps onto (cite the real
  endpoint/model, not an assumption).
- The date and who approved it (the User, per the standing AO-4
  governance — Claude does not unilaterally finalize a screen design).
