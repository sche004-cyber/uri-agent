# Rejected design decisions

This folder holds one record per screen design (or structural option) that
was considered and turned down, so the same idea is not re-proposed later
without knowing it was already rejected and why.

## Record format

Name each file `<screen-or-decision>_<YYYY-MM-DD>.md` and include:

- What was proposed (the concrete structure/layout).
- Which reference(s) it was adapted from.
- Why it was rejected (be specific — "too complex," "duplicates an
  existing real screen," "assumes a backend capability that doesn't
  exist," etc.).
- Whether any part of it is still worth revisiting later under different
  conditions, and what those conditions would be.
